# Nexora Prompt Images

Upload prompt preview images into this folder using these exact filenames:

- `prompt-01.jpg`
- `prompt-02.jpg`
- `prompt-03.jpg`
- `prompt-04.jpg`
- `prompt-05.jpg`
- `prompt-06.jpg`

The Prompt Book automatically detects these files. If an image exists, it replaces the gradient placeholder on the card and in the prompt popup. If an image is missing, the existing placeholder remains visible.

Recommended format: JPG, 4:3 or 1:1, optimized for web.
