FAQ

Questions, answered clearly.

Use this page to explain the program, student access, prompt library and creator resources before a customer joins.

What is Nexora Digital?

Nexora Digital is a creator learning hub focused on TikTok growth, AI-assisted content, practical creator systems and digital resources.

Do I need experience?

No. The learning path is designed so beginners can start with account foundations and build skills step by step.

What is included in the Support Program?

The program combines structured lessons, practical tasks, a student portal, private notes and digital creator resources.

How does the Prompt Book work?

Each card opens a larger panel with the title, category and prompt text. The library can later be connected to purchases and account-based unlocking.

Can I sign in with Google?

Yes. The student portal is prepared for Supabase authentication and Google sign-in once the new NexoraTikTok redirect URL is added to the Supabase allow list.

Will my progress stay saved?

The current portal keeps the account session and local notebook. Course progress can be connected to Supabase tables in the next backend step.
